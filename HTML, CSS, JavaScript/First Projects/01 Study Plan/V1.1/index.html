Soy Evan Ulises González Veloz, tengo 17 años. Estudiante de Ingenieria en Desarrollo de Software.

La "Ingeniería en Desarrollo de Software" forma profesionales capaces de diseñar, desarrollar y mantener soluciones tecnológicas innovadoras, con enfoque ético, colaborativo y orientado a la mejora de procesos y la sociedad.

Perfil de la carrera: La carrera se centra en el desarrollo de software para aplicaciones web, móviles y sistemas empresariales, utilizando tecnologías de vanguardia y metodologías ágiles.

Programación

La programación refiere a la acción de crear programas o aplicaciones a través del desarrollo de un código fuente, que se basa en el conjunto de instrucciones que sigue el ordenador para ejecutar un programa. "La programacion es un arte maravillosa".
